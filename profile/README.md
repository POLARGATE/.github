Hacemos software con IA para empresas: webs, CRM, asistentes y automatizaciones. Aquí dejamos, gratis, las piezas que usamos cada día para que montes lo tuyo.

### Qué hay aquí

- **[skills](https://github.com/POLARGATE/skills)**: skills de Claude Code listas para instalar. Te conectas una vez y cada mejora que subimos te llega sola.
- **[Biblioteca](https://biblioteca.polargate.ai)**: los kits, prompts y plantillas de nuestros vídeos.

### Instala las skills

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
```
